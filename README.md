| What | How it works in practice |
| --- | --- |
| **Launch scoring** | every pons mint is read from the pool on my own node and gets a calibrated score before the first retweet exists |
| **Predicted ATH** | a second model estimates the multiple from mint; the board keeps the receipt and the real ATH next to it |
| **Nightly retrain** | the model refits at 04:12 UTC on everything that graduated or died that day — paid for by the coin's 2.5% fee, not a subscription |
| **Alerts** | a Telegram bot that posts the score, the reasons and the contract, timestamped, 1.2 s after mint |

> Nothing here is a black box. If a number is on screen, the tool can show the block it came from.
